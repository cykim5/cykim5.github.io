Projects

OT-2 Tilting Plate Adapter

CadQueryPython3D printingStepper control

A 3D printed adapter that occupies one deck slot of an Opentrons OT-2 liquid handling robot and tilts the plate so liquid pools to one side of each well. Two stepper driven cams sit under a platform pivoting on a fixed ball, giving tilt in any direction up to 17 degrees.

Written as a parametric CAD model rather than drawn by hand, so dimensions regenerate from a parameter block. Before anything was printed I simulated 25 motor position combinations and checked every one for collisions and for the platform staying seated.

Gene-ius

LLM agentsKnowledge graphsPythonTeam of 5

An AI agent that helps laboratories interpret genetic variants of uncertain significance, which account for roughly a third of variants in ClinVar. Across 23 retina and heart genes it ranks which variants to test first, then answers whether a variant is harmful, how it breaks the protein, which disease follows, and what treatment strategy might fit.

Evaluated with a time machine design: the model sees only data available in January 2023 and is graded on variants experts resolved afterwards, so no variant is ever evidence for itself. It found 38 later-proven disease variants in its top 500, against 18 for AlphaMissense.

Biological Workflow Map

TaxonomyPythonData modeling

A map of 264 wet-lab workflows across eight domains, built so that every workflow has exactly one place. Each is filed by what it produces, which is the only attribute that does not overlap, so the structure holds where field-based and technique-based classifications collapse.

It is the base layer for assessing which laboratory work is worth automating. Feasibility and cost are scored against it rather than built into it, so the structure stays stable as robots improve.
